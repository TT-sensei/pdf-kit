# ファイル工房

PDF・画像を、もっとかんたんに。

学校現場で使いやすい、ブラウザ内完結型のファイル変換ツールです。

## MVP

- PDF → PNG / JPG / WebP
- PDFへのページ番号追加（開始番号・文字サイズ・配置を設定）
- PDF整理（ページサムネイルを見ながら並べ替え・削除。ドラッグと矢印操作）
- PDFへの文字入れ（日本語対応、位置・色・サイズ・対象ページを設定し、プレビューして保存）
- PDFの全ページ・ページ範囲変換
- 画像 → WebP（一括変換、品質、長辺サイズ、削減率）
- 画像 → PDF（複数画像、順番変更、削除、A4縦 / A4横 / 画像に合わせる）
- 個別ダウンロード / ZIP一括ダウンロード
- 進捗表示とキャンセル
- PC / Chromebook / iPad / スマートフォン対応

## プライバシー

選択したユーザーファイルは外部サーバーへアップロードせず、ブラウザ内で処理します。
CDNからPDF.js、pdf-lib、JSZipを読み込みますが、ユーザーが選択したファイルをこれらのCDNへ送信する設計にはしていません。

将来的にはライブラリのローカル配置によるオフライン利用も検討します。

## ライセンス・参考資料

Stirling-PDF（https://github.com/Stirling-Tools/Stirling-PDF）は機能調査の参考として確認しています。このリポジトリの機能追加では、Stirling-PDFのソースコード、独自ライセンス対象ディレクトリのコード、ロゴ・画像をコピーしていません。ページ番号機能は既存の pdf-lib を利用して独自に実装しています。将来コードを取り込む場合は、取り込み対象ファイルのライセンスを個別に確認し、必要な著作権表示とライセンス文を保持します。今回の文字入れ機能は、既存の pdf-lib とブラウザ内 Canvas API を使用し、Stirling-PDFのソースコードや画像はコピーしていません。
